# Contributing

Contributions should preserve the repository's evidence-first format.

For each compatibility claim, record:

- game version or Steam Build ID;
- macOS and Mac hardware family;
- wrapper, Wine engine, renderer, and BepInEx versions;
- exact symptom and conditions;
- observed result;
- evidence source, such as `Player.log`, module load logs, file hashes, or Chainloader output;
- confidence level.

Keep game files, save files, fonts, Unity corlibs, Mod archives, credentials, and personal paths out of commits. Use synthetic examples and redact Steam account identifiers.

Update all affected language guides when shared technical facts change. Translation improvements may target one language at a time.
